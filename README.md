# Vidun Damsana Portfolio

Personal portfolio website for Vidun Damsana, built with HTML, CSS and vanilla JavaScript.

## Easy updates
- Replace \`assets/profile-placeholder.svg\` with your own photo and update the image path in \`index.html\`.
- Edit the \`skills\` array in \`script.js\` to add/remove skills.
- Edit the \`projects\` array in \`script.js\` to add/remove projects.
- Replace the placeholder email and Facebook URL in \`index.html\`.

## GitHub Pages
This repository is named \`VidunD.github.io\`, so it is ready to be used as Vidun's GitHub Pages user site.

## Custom domain later
When a domain is purchased, open Repository Settings → Pages → Custom domain, add the domain, configure its DNS records, and enable HTTPS after DNS verification.
